# Deployment Guide

## 🚀 Deploy Ghostty Website Fork

### Local Development
```bash
make              # Start local server
open http://localhost:3000
```

### Deploy to Vercel

1. Connect repo to Vercel: https://vercel.com/new
2. Select GitHub repository
3. Vercel auto-detects configuration
4. Click Deploy
5. Auto-deploys on `git push origin main`

### Production Checklist

- [ ] Local build works: `make build`
- [ ] No console errors
- [ ] Performance acceptable
- [ ] Links working
- [ ] Mobile responsive
